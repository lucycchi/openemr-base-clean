# Extra section options

**Chosen:** Encounter history (user decision at Gate 2a, 2026-09-26; the recommendation was Vitals)

## Recommendation

**Vitals.** They're the most useful thing a clinician glances at before a visit, the old card is a single focused view (the latest vitals set), FHIR serves them through a dedicated vital-signs Observation service under scopes both auth options already have, and the Standard API can seed them with the existing seed client. The known risk (units and panel components) can be handled in the mapper and tested.

The next best is Immunizations: simple and fully in FHIR, but it can only be seeded through the UI, and the old card's missing ACL makes visibility parity awkward. Notes are ruled out because pnotes are not in FHIR.
